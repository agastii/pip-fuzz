To publish with Vercel:
1. Upload all files and the assets folder to a GitHub repository.
2. Import the repository into Vercel; no build command is needed for this static site.
3. Use the deployed URLs ending in /pip.html and /fuzz.html.
4. Generate separate QR codes from those final URLs and place the matching code on each tag.

Test the deployed pages and QR codes on a phone before printing. The pages explain the rewards; they do not automatically track customer card collections.
